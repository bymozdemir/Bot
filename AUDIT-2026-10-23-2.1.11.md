## Doğrulanan bulgular ve değişiklikler

1. **Paket sürümü tutarsızdı:** `package.json` `2.1.10-testnet-live-ready`, `package-lock.json` ise `2.1.7-testnet-gate` bildiriyordu; arşiv adı `2.1.11` idi. Paket ve lock kök sürümleri `2.1.11` ile eşitlendi.
2. **Git gizli dosya koruması yoktu:** `.gitignore` bulunmuyordu. `.env`, çalışma verisi (`data/`), loglar ve `node_modules/` için ignore kuralları eklendi.
3. **Güvenli örnek yapılandırma yoktu:** `.env.example` eklendi. Canlı işlem ve borsa bazlı izinler örnek yapılandırmada kapalı; kullanıcı bunları bilinçli olarak etkinleştirebilir.
4. **Arşivde kullanıcı çalışma verisi bulunmadı:** `.env`, `data/state.json`, `data/auth.json`, `data/credentials*.json`, loglar ve `node_modules/` arşivde yoktu. Bu nedenle bu arşiv, kullanıcı hesabı durumunu veya yerel kimlik bilgilerini taşımıyor.

- Tam test paketi bitmedi: `test/backtest.cli.test.js` harici URL/bağlantı bekleyişi nedeniyle toplu koşu zaman sınırını aştı. Bu, testin geçtiği anlamına gelmez.
- `npm ci` denendi ancak bu çalışma ortamında paket kayıt sunucusuna erişim/indirme zaman aşımına uğradı. Çevrimdışı npm önbelleğinde `ws` paketi yoktu. Bu yüzden temiz kurulum, tam test paketi ve bağımlılık güvenlik taraması bu oturumda doğrulanamadı.
- Kaynakta canlı motorun güvenlik kapıları ve borsa yetenek kontrolleri bulundu; fakat özel API kimlik doğrulaması, gerçek Testnet emir akışı, iptal/dolum yarışları ve yeniden başlatma sonrası gerçek borsa mutabakatı tüm desteklenen borsalarda uçtan uca doğrulanmış değildir.
- Bu çalışmada gerçek borsaya emir gönderilmedi ve gerçek kullanıcı API anahtarı kullanılmadı.

## Kullanım notu

Temiz kurulumda bağımlılıkları `npm ci` ile kurup önce `npm run preflight`, ardından `npm test` çalıştırın. Ağ erişimi gerektiren testler için bağlantıyı ayrıca doğrulayın. Gerçek borsada ilk testten önce yalnızca gerekli API izinlerini açın; para çekme izni botun alım-satım işlevi için gerekli değildir.
